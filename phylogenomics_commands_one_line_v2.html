How to use this page

↑ Back to top

Copy–paste workflow

  1. Log into the AWS instance using the credentials provided for the workshop (typically via SSH).
  2. Open RStudio Server in your browser and go to the Terminal tab (not the R Console).
  3. Navigate to your working directory, for example:
Change to your project directory
cd /path/to/your/project
  1. Use the Copy buttons to copy commands from this page into the Terminal.
  2. Always update file names, paths, and thread counts to match your own data and server limits.

Adapting paths & filenames

  • /path/to/..., my_alignment.fa, BUSCO001.fa, etc. are place-holders.
  • Replace them with your own:
    • BUSCO alignment directory
    • RAD / SNP matrices
    • Number of threads your AWS instance allows
Tip: Keep a simple text file (e.g. my_paths.txt) with your own directories and copy–paste from there.

1. Terminal sessions (byobu / screen)

↑ Back to top

Open the RStudio Terminal

  1. In RStudio Server, click the Terminal tab (next to the Console).
  2. If needed, create a new terminal via Terminal → New Terminal.

Create a named byobu session

This keeps long jobs running even if your browser or VPN drops.

Create a named byobu session (replace mysession)
byobu new -s mysession

Inside byobu, run all heavy commands (MAFFT, IQ-TREE, ASTRAL, etc.).

Reattach an existing byobu session

List and reattach sessions
# List existing sessions
byobu list-sessions

# Reattach (replace mysession)
byobu attach -t mysession
To detach from byobu but keep jobs running, press Ctrl+A then D.

2. Preparing FASTA data (pre- and post-alignment)

↑ Back to top

Count sequences in a FASTA file

Count records by header lines
grep -c "^>" my_sequences.fa

Remove duplicate sequences (optional)

If seqkit is available, you can quickly remove exact duplicate sequences:

Remove duplicate sequences with seqkit
seqkit rmdup -s my_sequences.fa -o my_sequences.dedup.fa
Alternative: If seqkit is not installed on your AWS image, you can skip this step or ask the instructor which deduplication tool is available.

3. Multiple sequence alignment (MAFFT)

↑ Back to top

DNA sequences – automatic strand direction

DNA MAFFT --adjustdirection

For DNA, you can use MAFFT’s --adjustdirection to automatically reverse-complement sequences so that they are aligned in the same direction as the first sequence in the file.

Single DNA FASTA file (direction-adjusted)
mafft --thread 2 --reorder --adjustdirection --maxiterate 1000 --auto dna_sequences.fas > dna_sequences.aligned.fas
Batch-align many DNA FASTA files
cd /path/to/fasta; for filename in *.fas; do mafft --thread 2 --reorder --adjustdirection --maxiterate 1000 --auto "$filename" > "${filename%.fas}.aligned.fas"; done
Important: Because --adjustdirection uses the first sequence as reference for orientation, make sure that this sequence is in the correct direction before running the alignment.

Align a single gene / locus (generic)

DNA / protein MAFFT L-INS-i
Align one FASTA file
mafft --maxiterate 1000 --localpair my_sequences.fa > my_sequences.aln.fa

Align many BUSCO genes in a folder

Assume each BUSCO file ends in .fa and lives in busco_fasta/.

Loop over all FASTA files
cd /path/to/busco_fasta; for f in *.fa; do echo "Aligning $f ..."; mafft --maxiterate 1000 --localpair "$f" > "${f%.fa}.aln.fa"; done

4. Trimming alignments (TrimAL)

↑ Back to top

Trim one alignment

Automatic trimming with TrimAL
trimal -in my_sequences.aln.fa -out my_sequences.aln.trim.fa -automated1

Trim all alignments in a folder

Loop over alignment files
cd /path/to/busco_fasta; for f in *.aln.fa; do echo "Trimming $f ..."; trimal -in "$f" -out "${f%.aln.fa}.aln.trim.fa" -automated1; done

5. Filtering short alignments (bioawk / bash)

↑ Back to top

Filter short sequences within each alignment

Example: keep only sequences with at least 150 aa (or nt) in each alignment.

Filter sequences by length (bioawk)
cd /path/to/busco_fasta; minlen=150; for f in *.aln.trim.fa; do echo "Filtering $f (min length ${minlen}) ..."; bioawk -c fastx -v L="$minlen" 'length($seq) >= L {print ">"$name"\n"$seq}' "$f" > "${f%.aln.trim.fa}.aln.trim.filt.fa"; done

Drop very short alignments before concatenation

Example: only keep alignments with at least 200 ungapped sites.

Keep only alignments ⩾ 200 columns
cd /path/to/busco_fasta; mincols=200; mkdir -p long_alignments; for f in *.aln.trim.filt.fa; do cols=$(bioawk -c fastx 'NR==1 {print length($seq); exit}' "$f"); if [ "$cols" -ge "$mincols" ]; then echo "Keeping $f ($cols columns)"; cp "$f" long_alignments/; else echo "Skipping $f ($cols columns)"; fi; done

6. Concatenating alignments (FASconCAT-G)

↑ Back to top
Executable name: On some systems the script may be called FASconCAT-G.pl, FASconCAT-G_v1.04.pl, or may require perl /path/to/FASconCAT-G.pl. Use whatever works on your AWS image.

Create a file list for FASconCAT-G

From the folder with your final per-gene alignments:

List all FASTA alignments
cd /path/to/busco_fasta/long_alignments

ls *.fa > FASconCAT_G.input

Run FASconCAT-G to create concatenated matrix + partitions

Example for a NEXUS output and IQ-TREE partition file.

Concatenate alignments with FASconCAT-G
perl FASconCAT-G.pl -s -n -p -l -o concat

# Expected key outputs (names may vary):
#   concat.fas              - concatenated alignment (FASTA)

7. Phylogenetic tree inference (IQ-TREE 3)

↑ Back to top
Important: The executable may be called iqtree, iqtree2 or iqtree3 depending on the installation. In all commands below we use iqtree2 as a placeholder – change it to whatever works on your AWS instance.
ModelFinder (-m MFP) UFBoot (-B) SH-aLRT (-alrt)

7.1 Single-gene tree with ModelFinder

Use ModelFinder (-m MFP) to select the best model, then infer an ML tree with SH-aLRT and ultrafast bootstrap support.

Single-gene ML tree with support
iqtree3 -s BUSCO001.aln.trim.filt.fa -m MFP -B 1000 -alrt 1000 -T AUTO --prefix BUSCO001_ML

7.2 Concatenated, partitioned analysis (BUSCO genes)

Use the concatenated matrix and FASconCAT-G partition file.

Partitioned concatenated tree with MFP+MERGE
iqtree3 -s concat.fas -p concat_partition.nex -m MFP+MERGE -B 1000 -alrt 1000 -T AUTO --prefix concat_ML
Why MFP+MERGE? IQ-TREE will both select a model per partition and merge similar partitions to reduce over-parameterisation.

Concatenated, partitioned analysis (BUSCO genes)

IQ-TREE 3 provides a new convenient feature: if you have a directory with many (locus) alignments, you can specify this directory directly with -p option:.

Partitioned concatenated tree with MFP+MERGE
iqtree3 -p directory -m MFP+MERGE -B 1000 -alrt 1000 -T AUTO --prefix concat_ML
Why MFP+MERGE? IQ-TREE will both select a model per partition and merge similar partitions to reduce over-parameterisation.

7.3 Gene / locus trees for ASTRAL or concordance factors

Given a directory with one alignment per locus (e.g. long_alignments/), you can infer one tree per locus:

Infer gene trees for all loci
cd /path/to/busco_fasta/long_alignments

iqtree3 -S . -m MFP -B 1000 -T AUTO --prefix loci
This uses the -S option to infer a separate tree for each alignment file in the directory and writes them to loci.loci.treefile, which we will use for ASTRAL and concordance factor analysis.

8. SNP / RAD-seq phylogenies (IQ-TREE)

↑ Back to top
Key point: SNP-only matrices typically lack constant sites. Use an ascertainment bias correction by adding +ASC to the model (e.g. GTR+ASC or MFP+ASC).

8.1 Single SNP matrix with +ASC

Example: SNP alignment snps.phy in PHYLIP/FASTA format (no constant sites).

Fixed model: GTR+ASC
iqtree3 -s snps.phy -m GTR+ASC -B 1000 -alrt 1000 -T AUTO --prefix snps_GTR_ASC
Let ModelFinder choose (+ASC enforced)
iqtree3 -s snps.phy -m MFP+ASC -B 1000 -alrt 1000 -T AUTO --prefix snps_MFP_ASC

8.2 Partitioned SNP / RAD-seq data

If your RAD / SNP dataset is partitioned by locus (e.g. one big concatenated SNP matrix with a partition file in NEXUS or RAxML style), you can combine partition models with ascertainment bias correction:

Partitioned SNP matrix with MFP+ASC
iqtree3 -s snps_concat.phy -p snps_partitions.nex -m MFP+ASC -B 1000 -alrt 1000 -T AUTO --prefix snps_concat_ASC
Read the log: For SNP data, always check the IQ-TREE .iqtree file to confirm that an +ASC model was actually used and that the number of variable and constant sites makes sense.

9. Species tree inference (ASTRAL)

↑ Back to top

Assume you already generated gene trees with IQ-TREE using -S . and obtained loci.loci.treefile (Section 7.3).

9.1 Run ASTRAL on gene trees

ASTRAL species tree
cd /path/to/busco_fasta/long_alignments

java -jar /path/to/astral.jar -i loci.loci.treefile -o species_tree.astral.tre 2> astral.log
Tip: If ASTRAL is wrapped in a module or script on your AWS system, replace java -jar /path/to/astral.jar with the local command (e.g. astral).

10. Concordance factors (gCF / sCF) with IQ-TREE

↑ Back to top

We use: (i) a species tree from the concatenated analysis (concat_ML.treefile), (ii) gene trees from loci.loci.treefile, and (iii) the concatenated alignment (concat.fas).

10.1 Compute gene and site concordance factors

gCF + sCF for concatenated tree
cd /path/to/busco_fasta/long_alignments

iqtree3 -t concat_ML.treefile --gcf loci.loci.treefile -s ../concat.fas --scf 100 -T AUTO --prefix concat_cf
This annotates each branch in concat_ML.treefile with bootstrap (from the original IQ-TREE run) plus gCF and sCF values, written to concat_cf.cf.tree and concat_cf.cf.stat. You can visualise these in FigTree or iTOL to compare support vs concordance.
